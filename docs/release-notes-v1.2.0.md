## ダウンロード

`FavoriteShortcut.exe` … これ1つで動きます（.NET 不要）
`FavoriteShortcut-portable.zip` … 上記 + README / LICENSE

v1.1.0 以前から更新する場合は **EXE を上書きするだけ**です。登録したデータはそのまま残ります。

## 新機能: 英語表示に対応 / English UI

設定 → 表示 → **言語** で選べます。

- **自動（既定）** … Windows の表示言語が日本語なら日本語、それ以外は英語
- **日本語** / **English** … 常にその言語で表示

選んだ瞬間に画面全体が切り替わります（再起動は不要）。
登録したタイトル・フォルダ名・タグは翻訳されません。

The app now follows your Windows display language automatically: Japanese on Japanese Windows, English everywhere else.
You can also choose it in Settings → Display → Language. The change applies instantly, without restarting.

## 動作環境

Windows 10 (1809 以降) / Windows 11 の 64bit

初回起動時の「WindowsによってPCが保護されました」は、未署名のアプリのため出るものです。
**詳細情報** → **実行** で起動できます。
