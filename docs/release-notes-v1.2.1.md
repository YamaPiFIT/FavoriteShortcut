## ダウンロード

`FavoriteShortcut.exe` … これ1つで動きます（.NET 不要）
`FavoriteShortcut-portable.zip` … 上記 + README / LICENSE

v1.2.0 以前から更新する場合は **EXE を上書きするだけ**です。登録したデータはそのまま残ります。

## 改善: ショートカットが多くても重くならないように

1 万件のデータでの比較です。

| 操作 | v1.2.0 | v1.2.1 |
|---|---|---|
| 起動 | 2.5 秒 | 1.2 秒 |
| カード表示で検索（1 文字ごと） | 0.8〜1.6 秒 | 0.04〜0.15 秒 |
| 30 件まとめて削除 | 6.1 秒 | 0.15 秒 |
| タグ名の変更（263 件） | 49 秒 | 0.22 秒 |
| お気に入り 500 件の取り込み | 117 秒 | 0.52 秒 |

データの形式は変わっていません。以前のバージョンに戻しても、そのまま開けます。

Much faster with many shortcuts. Your data format is unchanged.

## 変更

- 検索語を変えたときやフォルダを切り替えたときは、一覧を先頭から表示するようにしました
- リスト表示で下へスクロールした状態から検索欄で ↓ を押すと、先頭の項目まで戻るようにしました
- 共有フォルダなどネットワーク上の項目のアイコンは、いったん標準のアイコンで表示してから切り替えます（つながらないときに画面が固まらないように）

## 動作環境

Windows 10 (1809 以降) / Windows 11 の 64bit

初回起動時の「WindowsによってPCが保護されました」は、未署名のアプリのため出るものです。
**詳細情報** → **実行** で起動できます。
