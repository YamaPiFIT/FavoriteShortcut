## 新機能

### ブラウザのお気に入りを取り込めるようになりました

`⋯` →「ブラウザのお気に入りを取り込む...」から、Edge や Chrome に貯めてあるお気に入りを
まとめて登録できます。

- **取り込み元のブラウザを選択**できます（Microsoft Edge / Google Chrome。
  Brave / Vivaldi / Opera / Chromium も同じ形式のためインストールされていれば選べます）
- 複数プロファイルがある場合は、ブラウザ側で付けた名前で区別できます
- 取り込む範囲（お気に入りバー / その他 / モバイル）を個別に選べます
- ブラウザのフォルダ構成をそのまま再現できます
- すでに登録済みの URL はスキップできます
- 取り込んだ項目にまとめてタグを付けられます

ブラウザのファイルは読み取るだけで、お気に入り側には一切変更を加えません。
ブラウザを起動したままでも取り込めます。

### ブラウザが保存しているアイコンを使えるようになりました

これまで取得できなかったサイトのアイコンが表示されるようになりました。

- bot 対策で HTTP アクセスが拒否されるサイト
- ログインや SSO が必要な社内サイト
- JavaScript で描画されるサイト、SVG しか配信していないサイト

**一度ブラウザで開けばアイコンが付きます。** ショートカットを起動すると、
ブラウザ側がアイコンを保存するのを待って自動的に取り直します。

対応ブラウザ: Chrome / Edge / Brave / Vivaldi / Opera / Chromium / Firefox

通信は行わず、登録済みの URL だけをローカルで検索します。
不要であれば 設定 → アイコン から無効にできます。

## 改善

- **社内サイトのアイコンが取得できなかった問題を修正**しました。
  これまでホスト名だけから `https://ホスト名/` を組み立て直していたため、
  http のみのサイト・非標準ポート・サブパスに置かれたシステムを取りこぼしていました。
  登録された URL をそのまま使うようになっています。
- `http://` と `https://`、ポート違いのサイトが同じアイコンを共有してしまう問題を修正しました。

## 変更

- **外部のアイコン取得サービス（Google の favicon API）を廃止**しました。
  ローカルで同じ目的を達成できるようになったためです。
  これにより、このアプリが利用者の知らない第三者と通信することはなくなりました。
