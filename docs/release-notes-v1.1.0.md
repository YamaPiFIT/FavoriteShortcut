## ダウンロード

`FavoriteShortcut.exe` … これ1つで動きます（.NET 不要）
`FavoriteShortcut-portable.zip` … 上記 + README / LICENSE

v1.0.0 から更新する場合は **EXE を上書きするだけ**です。登録したデータはそのまま残ります。

## 新機能

### Edge / Chrome のお気に入りを取り込めます

`⋯` →「ブラウザのお気に入りを取り込む...」

- 取り込み元のブラウザとプロファイルを選択できます
- 取り込む範囲（お気に入りバー / その他 / モバイル）を個別に選べます
- ブラウザのフォルダ構成をそのまま再現できます
- 登録済みの URL はスキップ、まとめてタグ付けも可能です

ブラウザのファイルは読み取るだけで、お気に入り側は変更しません。起動したままでも取り込めます。
Brave / Vivaldi / Opera / Chromium も同じ形式のため選択できます。

### ブラウザが保存しているアイコンを使えます

bot 対策で拒否されるサイト、ログインが必要な社内サイト、JavaScript で描画されるサイトなど、
これまで取得できなかったアイコンが表示されるようになりました。

**一度ブラウザで開けばアイコンが付きます。** 通信は行わず、登録済みの URL だけをローカルで検索します。
対応: Chrome / Edge / Brave / Vivaldi / Opera / Chromium / Firefox

## 改善

- **社内サイトのアイコンを取得できない問題を修正。** http のみのサイト、非標準ポート、
  サブパスに置かれたシステムを取りこぼしていました
- `http` と `https`、ポート違いのサイトが同じアイコンを共有する問題を修正

## 変更

**外部のアイコン取得サービス（Google の favicon API）を廃止しました。**
ローカルで同じ目的を達成できるためです。これにより、このアプリが利用者の知らない
第三者と通信することはなくなりました。

## 動作環境

Windows 10 (1809 以降) / Windows 11 の 64bit

初回起動時の「WindowsによってPCが保護されました」は、未署名のアプリのため出るものです。
**詳細情報** → **実行** で起動できます。
