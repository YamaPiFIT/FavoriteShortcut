Windows 用の「お気に入り管理 + ランチャー」アプリ、最初のリリースです。

Web サイト・フォルダ・ファイルへのショートカットをフォルダとタグで整理して、
**どのアプリを使っていても `Ctrl + Space` → 検索 → `Enter` の 3 ステップで開ける**ことを目的にしています。

## ダウンロード

| ファイル | 内容 | .NET のインストール |
|---|---|---|
| `FavoriteShortcut.exe` | これ 1 つで動きます（約 68 MB） | **不要** |
| `FavoriteShortcut-portable.zip` | 上記 + README / LICENSE（約 62 MB） | **不要** |

どちらも中身は同じです。EXE を直接落とすほうが手軽ですが、ブラウザによっては警告が出るので、
その場合は ZIP のほうをご利用ください。

## 使い方

1. ダウンロードした EXE を好きな場所（デスクトップ、ドキュメント、USB メモリなど）に置いてダブルクリック
2. `＋ 新規登録` かエクスプローラーからのドラッグ＆ドロップで登録
3. `Ctrl + Space` でランチャーを開き、キーワードを入力して `Enter` で起動

登録したデータは **EXE と同じ場所に作られる `Data` フォルダ**に保存されます。
EXE とこのフォルダを一緒にコピーすれば、別の PC でもそのまま同じ内容で使えます。

## 主な機能

- Web URL / フォルダ / ファイル / UNC パスの登録と、種別の自動判定
- フォルダ階層とタグによる整理（日本語 IME 対応。入力して `Space` で確定）
- タイトル / タグ / フォルダ名 / URL・パス / メモ を横断する部分一致検索と、複数ワードの AND 検索
- グローバルホットキー（既定 `Ctrl + Space`、変更可）によるランチャー
- favicon の自動取得と、Windows のファイル / フォルダアイコンの表示
- エクスプローラーからのドラッグ＆ドロップ登録、フォルダ間のドラッグ移動
- ZIP でのエクスポート / インポート（フォルダ構成・タグ・アイコン・設定を保持）
- タスクトレイ常駐、Windows サインイン時の自動起動
- ライト / ダークテーマ、カード表示 / リスト表示

## 動作環境

Windows 10 (1809 以降) / Windows 11 の 64bit

## ご注意

初回起動時に「WindowsによってPCが保護されました」と表示されます。
個人で作成した未署名のアプリのため出るもので、**詳細情報** → **実行** で起動できます。
